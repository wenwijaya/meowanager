One word for the human this agent works for: **Meowanager**.

The human is Kucing hitam — a black cat who runs the show from the night shift: terse orders, exacting standards, bounties and free mints chased past midnight. A manager, but a cat. The pun lands on its own, it names the role that signs off on the work, and it is specific enough to remember and repeat.

## Run it

```sh
node main.ts
```

Node 22.18 or later runs the TypeScript directly. The program writes the single word to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`), world-readable, and exits 0.
